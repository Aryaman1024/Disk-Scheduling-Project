# Disk-Scheduling-Project
The Disk Scheduling Algorithms Project, based on Operating Systems, implements FCFS, SSTF, SCAN, C-SCAN, and LOOK to manage disk requests efficiently. It calculates seek time and request order, helping analyze performance and improve disk access efficiency in systems.

# Disk Scheduling Algorithms Project

# Description
This project is based on Operating Systems concepts and demonstrates how different disk scheduling algorithms manage disk requests efficiently. It compares multiple algorithms to minimize seek time and improve system performance.

# Algorithms Implemented
- FCFS (First Come First Serve)
- SSTF (Shortest Seek Time First)
- SCAN
- C-SCAN
- LOOK

# Objectives
- Understand disk scheduling techniques
- Compare performance of different algorithms
- Minimize seek time
- Improve disk efficiency

# Technologies Used
- Programming Language: (Java / C / C++ – update yours)

# How to Run
1. Open the project in your IDE
2. Compile the code
3. Run the main file
4. Enter disk requests and initial head position
5. View output (seek time & sequence)

# Output
- Displays total seek time
- Shows order of disk head movement
- Compares efficiency of algorithms
